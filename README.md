## Setup & Build
1. Clone repository:
   ```bash
   git clone https://github.com/user/chouhan-star.git
   ```
2. Open in Android Studio or build with Gradle:
   ```bash
   gradle :app:assembleDebug
   ```
3. Run Windows Companion Server (optional):
   ```bash
   python windows-companion/main.py
   ```
